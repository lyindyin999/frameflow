# FrameFlow

A visual workspace for creators to plan shoots, collect references, and move projects from idea to delivery.

**Live demo:** https://lyindyin999.github.io/frameflow/

## What is inside

- Visual project pipeline
- Moodboard-style project cards
- Task tracking and progress
- Search
- Project creation
- Persistent local workspace via localStorage
- Responsive dark UI
- Automated TypeScript + production build checks
- Automated GitHub Pages deployment

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Lucide React
- GitHub Actions

## Run locally

```bash
git clone https://github.com/lyindyin999/frameflow.git
cd frameflow
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
npm run typecheck
npm run build
```

## Product direction

FrameFlow is designed as an MVP for a creator-focused SaaS product. A future Pro plan could add cloud sync, team workspaces, AI-assisted reference search, client review links, and storage.
